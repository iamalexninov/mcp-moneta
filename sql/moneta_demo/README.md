# MonetaDemo SQL scripts

Local Moneta-like SQL Server database (tables, views, functions, stored procedures, fictional demo data).
Full guide: [docs/10-moneta-demo-database.md](../../docs/10-moneta-demo-database.md)

Run in SSMS in this order (File → Open → F5): `01` → `02` → `03` → `04` → `05` → `06`, then `07` (set the password first) and explore with `08`.
`99_drop_database.sql` removes everything to start over.
