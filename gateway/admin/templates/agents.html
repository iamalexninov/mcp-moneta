AI Agents

All assistants connect to the same MCP gateway: {{ settings.mcp_resource_url }}. Access is always per user, through OAuth 2.1 sign-in on this server.

Claude.ai Supported

Free plan: 1 custom connector. Pro/Max/Team/Enterprise: multiple.

  1. Open Customize → Connectors → Add custom connector.
  2. Name: Moneta. URL: {{ settings.mcp_resource_url }}.
  3. Leave OAuth client empty (automatic registration). Click Add, then Connect.
  4. Sign in here with your Moneta account and approve the permissions.
  5. In a chat, enable the connector from the + → Connectors menu.

Claude Desktop / Claude Code Supported

Desktop uses the same connector as Claude.ai (added once, available everywhere). Claude Code:

claude mcp add --transport http moneta {{ settings.mcp_resource_url }}

Then run /mcp in Claude Code to sign in.

ChatGPT Beta

  1. Settings → Apps & Connectors → Advanced → enable Developer mode (plan-dependent).
  2. Create connector with the MCP URL above, authentication OAuth.

Cursor Beta

Add to ~/.cursor/mcp.json:

{ "mcpServers": { "moneta": { "url": "{{ settings.mcp_resource_url }}" } } }
